# Local Yoke 1.14 compatibility

This project uses a local copy of @hecer/yoke 1.14.0 in `.yoke/tooling/yoke`. The global installation is unchanged. `yoke-1.14.patch` records every local package change: streaming SHA-256 for large tracked runtime DLLs; MCP newline framing and actual Graphify 0.9.55 identification; Serena structured-result decoding; workspace-ID discovery and readable MCP result text; wiring plain review findings into the existing routed repair loop. All fingerprint bytes and normal loop gates remain enforced.

The ignored local package copy includes its original `dist`, `canon`, `node_modules`, and `package.json`. To reconstruct it, copy those from the installed version 1.14.0 and apply this patch to the copy. Backend command locations in `.yoke/config.yaml` and the facade location in `.codex/config.toml` are specific to this Windows checkout and must be adjusted for another machine. Graphify uses graphifyy 0.9.55; Graft is pinned to 05760b07abc0e427f5af8ad378889ee402c5afc6; Serena to 701e7c843f46c6a649203a488cece1bf19f1df90.

Run from the repository root: `rtk proxy node .yoke/compatibility/run.mjs`. Use `--resume` only for a retained failed worktree and `--first` to stop after one story. The launcher uses normal Yoke routing, isolation, acceptance/full-suite gates and read-only review fingerprint checks. Its independent reviewer is a fresh Codex invocation with a different model from the implementer. The actual model is verified from the exact provider session record; schema-constrained verdicts are parsed by Yoke. Tests are executed by the supervisor outside the reviewer sandbox and tied to the source fingerprint. No approval is synthesized and no failing gate is suppressed.

The quality-loop compatibility patch forwards all actionable blockers from the same independent verdict to the routed repair worker, preserving the primary finding. Every repair still reruns criterion and full-suite gates and requires a fresh review; failure and repair-budget checks are unchanged. Verify this contract with `rtk proxy node .yoke/compatibility/check-repair-feedback.mjs`.
